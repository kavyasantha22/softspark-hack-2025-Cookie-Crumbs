# 🚀 SparkPlay Demo Guide - Notifications

## 📱 Testing Notifications

### **1. Initial Setup**
1. **Build & Run** the app on a physical device (notifications work better on real devices)
2. **Allow Notifications** when prompted on first launch
3. **Go to Settings** (Profile tab → Notifications) to verify permissions

### **2. Quick Test Notifications**

#### **Test Notification Button**
- Go to **Profile → Notifications**
- Tap **"Test Notification"** 
- Should see immediate notification: *"Test Notification! 🧪"*

#### **Create a Spark (Immediate Notifications)**
1. Tap the **+ button** in tab bar
2. Fill out spark details
3. Set duration to **5-10 minutes** from now
4. Tap **"Add Spark"**
5. **Immediately see**: *"New Spark Created! ✨"*

#### **Join a Spark (Immediate Notifications)**
1. Go to **Home** tab
2. Tap **"View"** on any available spark
3. Tap **"Join Spark"**
4. **Immediately see**: *"Spark Joined! 🎉"*

### **3. Scheduled Notifications (For Demo)**

#### **Quick Demo Setup (2-3 minutes)**
1. **Create a spark** that ends in **3 minutes**
2. **Join the spark**
3. **Wait 1-2 minutes**
4. You'll get: *"Spark Ending Soon! 🔥"* (10 min before end)

#### **Realistic Demo Setup (15-20 minutes)**
1. **Create a spark** that ends in **20 minutes**
2. **Join the spark**
3. **Wait 5 minutes**
4. You'll get: *"Spark Starting Soon! ⚡"* (15 min before)
5. **Wait another 10 minutes**
6. You'll get: *"Spark Ending Soon! 🔥"* (10 min before end)

## 🛠️ Making Notifications More Demo-Friendly

### **Current Notification Types:**
- ✅ **Immediate**: Spark created, joined, new participant
- ⏰ **Scheduled**: 15-min warning, 10-min ending alert
- 🎛️ **Customizable**: User can adjust timing

### **Demo Tips:**

#### **For Immediate Impact:**
- Use **Test Notification** button frequently
- Create multiple sparks to show creation notifications
- Join/leave sparks to show instant feedback

#### **For Scheduled Demos:**
- Create sparks with **very short durations** (2-5 minutes)
- Set custom reminder times to **1-2 minutes** for faster demos
- Use iPhone's **notification center** to show pending notifications

#### **Visual Demo Elements:**
- Notification permission status in Profile (green checkmark)
- Badge count on app icon (when notifications are pending)
- Rich notification content with emojis and clear messaging

## 🚨 Troubleshooting

### **Notifications Not Appearing?**
1. Check notification permissions in iOS Settings
2. Verify app is not in "Do Not Disturb" mode
3. Make sure app is backgrounded when testing scheduled notifications
4. Use Test Notification button to verify basic functionality

### **Scheduled Notifications Not Working?**
1. Create sparks with very short durations for testing
2. Check pending notifications in Notification Settings
3. Ensure device time zone is correct
4. Background the app after creating/joining sparks

### **Demo Going Too Fast?**
1. Use longer spark durations and show pending notifications in Settings
2. Focus more on immediate notifications and settings UI
3. Show notification customization options instead of waiting
